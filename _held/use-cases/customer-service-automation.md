# Customer Service Automation

A customer-service assistant and a workflow-building assistant should have different responsibilities.

A customer-service workflow can answer:

- product and feature questions;
- account/support questions;
- documented integration availability;
- where to find tutorials.

When the customer asks to **design or modify a workflow**, route the request to Flowi Ask AI or the workflow documentation rather than silently turning the support bot into a workflow generator.
