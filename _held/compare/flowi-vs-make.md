# Flowi vs Make

Both Flowi and Make can be used to create visual automations.

## Flowi — audited capabilities

- visual component workflows;
- AI models and agents;
- Custom Components;
- Universal Webhook;
- typed component connections;
- Google Workspace component families;
- Ask AI workflow assistance.

## Make — documented capabilities

Make's official Help Center documents Custom Webhooks and AI Agent scenarios, including webhook-triggered agent workflows.

Primary source: https://help.make.com/

## Evaluation criteria

Compare the platforms using your own requirements:

- integration availability;
- workflow control;
- AI workflow needs;
- customization/extensibility;
- operations and support;
- deployment and governance needs.

This page does not claim a universal winner.
