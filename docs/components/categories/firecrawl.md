# firecrawl components

Machine-readable reference: [`../../ai/components/firecrawl.json`](../../ai/components/firecrawl.json)

| Component ID | Display name | Status | Description |
|---|---|---|---|
| `firecrawl.FirecrawlCrawlApi` | Firecrawl Crawl API | AVAILABLE | Crawls a URL and returns the results. |
| `firecrawl.FirecrawlExtractApi` | Firecrawl Extract API | AVAILABLE | Extracts data from a URL. |
| `firecrawl.FirecrawlMapApi` | Firecrawl Map API | AVAILABLE | Maps a URL and returns the results. |
| `firecrawl.FirecrawlScrapeApi` | Firecrawl Scrape API | AVAILABLE | Scrapes a URL and returns the results. |

For new workflows, prefer `AVAILABLE` components. Do not create new flows with `LEGACY` components unless maintaining older workflows.
