# git components

Machine-readable reference: [`../../ai/components/git.json`](../../ai/components/git.json)

| Component ID | Display name | Status | Description |
|---|---|---|---|
| `git.GitLoaderComponent` | Git | AVAILABLE | Load and filter documents from a local or remote Git repository. Use a local repo path or clone from a remote URL. |
| `git.GitExtractorComponent` | GitExtractor | AVAILABLE | Analyzes a Git repository and returns file contents and complete repository information |

For new workflows, prefer `AVAILABLE` components. Do not create new flows with `LEGACY` components unless maintaining older workflows.
