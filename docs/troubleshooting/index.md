# Troubleshooting

Start by identifying whether the problem is:

- component availability;
- connection/type compatibility;
- credentials/connections;
- webhook/request shape;
- model provider configuration;
- legacy component migration;
- runtime data.

The machine-readable core error guide is [`../ai/ERROR_INDEX.json`](../ai/ERROR_INDEX.json).
