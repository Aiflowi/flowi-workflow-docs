# scrapegraph components

Machine-readable reference: [`../../ai/components/scrapegraph.json`](../../ai/components/scrapegraph.json)

| Component ID | Display name | Status | Description |
|---|---|---|---|
| `scrapegraph.ScrapeGraphMarkdownifyApi` | ScrapeGraph Markdownify API | AVAILABLE | Given a URL, it will return the markdownified content of the website. |
| `scrapegraph.ScrapeGraphSearchApi` | ScrapeGraph Search API | AVAILABLE | Given a search prompt, it will return search results using ScrapeGraph's search functionality. |
| `scrapegraph.ScrapeGraphSmartScraperApi` | ScrapeGraph Smart Scraper API | AVAILABLE | Given a URL, it will return the structured data of the website. |

For new workflows, prefer `AVAILABLE` components. Do not create new flows with `LEGACY` components unless maintaining older workflows.
