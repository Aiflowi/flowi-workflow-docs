# Telegram Webhook Setup

**Telegram Webhook Setup** is a documented Flowi extension component used to register a Flowi/Langflow webhook URL with the Telegram Bot API.

It is a **setup/administrative component**, not the component that receives every message.

## Inputs

| Input | Required | Secret | Purpose |
|---|---:|---:|---|
| Telegram Bot Token | Yes | Yes | Token issued for the Telegram bot |
| Flowi Webhook URL | Yes | No | Public HTTPS endpoint generated by the Flowi Webhook component |
| Flowi API Key | No | Yes | Optional authentication used by the Flowi webhook deployment |
| Drop Old Pending Messages | No | No | When enabled, requests Telegram to discard queued updates during registration |

The documented default for **Drop Old Pending Messages** is enabled.

## Output

`Webhook Setup Result` returns a `Data` result describing whether registration succeeded and includes the Telegram registration/verification response.

## What it does

The current documented implementation:

1. validates that a Telegram Bot Token was provided;
2. validates that a Flowi webhook URL was provided;
3. requires the webhook URL to use HTTPS;
4. calls Telegram Bot API `setWebhook`;
5. requests `message` and `callback_query` update types;
6. optionally drops pending updates;
7. checks the registration using `getWebhookInfo`.

## Recommended student procedure

1. Add the built-in **Webhook** component and obtain its public HTTPS endpoint.
2. Add **Telegram Webhook Setup**.
3. Enter the bot token in the secret field.
4. Paste the Flowi webhook endpoint into **Flowi Webhook URL**.
5. Add the Flowi API Key only if your webhook deployment requires it.
6. Decide whether old queued Telegram updates should be dropped.
7. Run the setup component.
8. Confirm that the result reports successful registration.
9. Build the runtime path separately: `Webhook.JSON → Telegram Update Parser`.

## Important safety note

Do not publish real bot tokens or API keys. Do not copy webhook registration output into public support chats without checking whether the returned webhook URL contains authentication information.

For the external API behavior, refer to Telegram's official Bot API documentation for `setWebhook` and `getWebhookInfo`: https://core.telegram.org/bots/api
