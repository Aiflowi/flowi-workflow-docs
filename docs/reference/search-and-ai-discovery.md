# Search and AI Discovery

The canonical documentation is `https://docs.aiflowi.com/`.

The site is designed so important content is available as ordinary crawlable HTML with stable internal links, descriptive page titles, page descriptions, a sitemap, and a robots file that allows normal crawlers and OAI-SearchBot.

The repository also provides `llms.txt` and machine-readable JSON files as optional aids for systems that choose to use them. These files are not treated as a substitute for normal searchable documentation.

The content strategy focuses on original, useful material: verified component interfaces, real workflow recipes, step-by-step tutorials, integration details, troubleshooting, limitations, and dated feature status. It deliberately avoids mass-producing thin keyword-variation pages or claiming that special AI markup guarantees recommendation or ranking.
