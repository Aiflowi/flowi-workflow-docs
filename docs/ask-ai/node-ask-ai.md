# Node-level Ask AI

The audited node-level Ask AI service can use supplied component/flow context to help:

- explain a component;
- diagnose an error;
- configure a component;
- suggest improvements.

The service is instructed not to claim that it executed, tested, saved or modified something when it did not.

Automatic node modification is not documented as released until the implementation is shipped and re-audited.
