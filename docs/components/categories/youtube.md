# youtube components

Machine-readable reference: [`../../ai/components/youtube.json`](../../ai/components/youtube.json)

| Component ID | Display name | Status | Description |
|---|---|---|---|
| `youtube.YouTubeChannelComponent` | YouTube Channel | AVAILABLE | Retrieves detailed information and statistics about YouTube channels as a DataFrame. |
| `youtube.YouTubeCommentsComponent` | YouTube Comments | AVAILABLE | Retrieves and analyzes comments from YouTube videos. |
| `youtube.YouTubePlaylistComponent` | YouTube Playlist | AVAILABLE | Extracts all video URLs from a YouTube playlist. |
| `youtube.YouTubeSearchComponent` | YouTube Search | AVAILABLE | Searches YouTube videos based on query. |
| `youtube.YouTubeTranscripts` | YouTube Transcripts | AVAILABLE | Extracts spoken content from YouTube videos with multiple output options. |
| `youtube.YouTubeTrendingComponent` | YouTube Trending | AVAILABLE | Retrieves trending videos from YouTube with filtering options. |
| `youtube.YouTubeVideoDetailsComponent` | YouTube Video Details | AVAILABLE | Retrieves detailed information and statistics about YouTube videos. |

For new workflows, prefer `AVAILABLE` components. Do not create new flows with `LEGACY` components unless maintaining older workflows.
