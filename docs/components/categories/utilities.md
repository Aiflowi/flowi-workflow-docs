# utilities components

Machine-readable reference: [`../../ai/components/utilities.json`](../../ai/components/utilities.json)

| Component ID | Display name | Status | Description |
|---|---|---|---|
| `utilities.CalculatorComponent` | Calculator | AVAILABLE | Perform basic arithmetic operations on a given expression. |
| `utilities.CurrentDate` | Current Date | AVAILABLE | Returns the current date and time in the selected timezone. |
| `utilities.PythonREPLComponent` | Python Interpreter | AVAILABLE | Run Python code with optional imports. Use print() to see the output. |
| `utilities.IDGenerator` | ID Generator | LEGACY | Generates a unique ID. |

For new workflows, prefer `AVAILABLE` components. Do not create new flows with `LEGACY` components unless maintaining older workflows.
