# Connections and Credentials

Connections give Flowi workflows authenticated access to external systems.

Public documentation never contains credential values.

Current audited connection mechanisms include:

- Google Connections for verified Google Workspace component families;
- Global Variables for reusable stored values and credentials;
- Model Provider credential configuration;
- Flowi API key settings.

See the machine-readable [`CONNECTION_INDEX.json`](../ai/CONNECTION_INDEX.json).
