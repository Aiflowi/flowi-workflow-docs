# Model Providers and Global Variables

Flowi includes model-provider configuration and reusable stored variables.

## Model provider credentials

The audited provider service can:

- list providers and models;
- identify configured providers;
- validate provider credentials when saved;
- enable/disable models;
- select default models.

## Global Variables

Workflow fields can reference stored variables instead of embedding values directly in the flow.

For public examples, show **variable names or placeholders**, never real credentials.
