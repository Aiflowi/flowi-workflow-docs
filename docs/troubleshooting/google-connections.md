# Google Connection Troubleshooting

Check:

1. a Google Connection is selected;
2. the signed-in account has the required permissions;
3. the connection contains the required scopes;
4. reauthorization succeeds if the token can no longer refresh.

The audited implementation can refresh expired access tokens and persist refreshed token information.
