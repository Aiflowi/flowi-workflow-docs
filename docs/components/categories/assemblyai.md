# assemblyai components

Machine-readable reference: [`../../ai/components/assemblyai.json`](../../ai/components/assemblyai.json)

| Component ID | Display name | Status | Description |
|---|---|---|---|
| `assemblyai.AssemblyAIGetSubtitles` | AssemblyAI Get Subtitles | AVAILABLE | Export your transcript in SRT or VTT format for subtitles and closed captions |
| `assemblyai.AssemblyAILeMUR` | AssemblyAI LeMUR | AVAILABLE | Apply Large Language Models to spoken data using the AssemblyAI LeMUR framework |
| `assemblyai.AssemblyAIListTranscripts` | AssemblyAI List Transcripts | AVAILABLE | Retrieve a list of transcripts from AssemblyAI with filtering options |
| `assemblyai.AssemblyAITranscriptionJobPoller` | AssemblyAI Poll Transcript | AVAILABLE | Poll for the status of a transcription job using AssemblyAI |
| `assemblyai.AssemblyAITranscriptionJobCreator` | AssemblyAI Start Transcript | AVAILABLE | Create a transcription job for an audio file using AssemblyAI with advanced options |

For new workflows, prefer `AVAILABLE` components. Do not create new flows with `LEGACY` components unless maintaining older workflows.
